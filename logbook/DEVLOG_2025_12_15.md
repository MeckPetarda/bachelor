# Development Log - ESP32 GPIO Implementation

**Date:** December 15, 2024
**Task:** Implement GPIO control for buttons, LEDs, and PIR sensor

## Objective

Create ESP32 GPIO application with debounced button inputs, LED outputs, and PIR motion sensor for attendance system development board.

## Configuration

### Components
- **LED Outputs:** GPIO5, GPIO18 (100Ω resistors)
- **Button Inputs:** GPIO34, GPIO35 (external 10kΩ pull-ups required)
- **PIR Sensor:** GPIO2 (initially GPIO3, moved due to strapping pin conflict)

### Features
- 20ms software debouncing for buttons
- 100ms debouncing for PIR sensor
- ISR-based edge detection with deferred processing

## Issues Resolved

### GPIO3 Strapping Pin Conflict
**Problem:** PIR sensor on GPIO3 didn't work
**Cause:** GPIO3 is U0RXD (UART0 RX) and strapping pin used during boot
**Solution:** Moved to GPIO2

### Onboard LED on GPIO2
GPIO2 has hardwired onboard LED on Hornaxys devboard - lights during motion detection (acceptable visual indicator).

## Technical Notes

- GPIO34/35 are input-only pins with no internal pull-up/pull-down capability
- External pull-ups mandatory for stable operation
- Strapping pins (GPIO0, GPIO2, GPIO3, GPIO15) require careful consideration

## Test Results

✓ Button debouncing working correctly
✓ LED control functional
✓ PIR sensor detects motion with proper debouncing
✓ No false triggers or bounce issues
